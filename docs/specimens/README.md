# Specimens

Manuscript samples shared by the README screenshots (`scripts/screenshots.ts`) and the website
(`website/scripts/samples.ts`), so both show the same text.

- `neko.jpnov` — 夏目漱石『吾輩は猫である』冒頭（青空文庫、パブリックドメイン）. The repository's one
  non-placeholder text; every use carries this credit (both README hero captions, the site's hero
  and 組版 specimens). Replace it only together with those captions.
- `notation.jpnov` — one annotation per line, display width ≤ 9 cells. Placeholder prose.
- `kinsoku.jpnov` — at 20 cells per line, `kinsoku: none` starts line 2 with 。 and ends it with 「;
  `strict` hangs the 。 on line 1 and keeps the 「 inside the line. Placeholder prose.
